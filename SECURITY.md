# Security policy

Please report vulnerabilities privately with GitHub's **Report a vulnerability** button (Security tab → Advisories), not in a public issue.

We're especially interested in anything that could:
- expose chat content;
- make the extension send data without the user turning on sync;
- let a web page tamper with stored totals;
- leak dashboard ingest keys or provider admin keys.

We aim to reply within 7 days.
